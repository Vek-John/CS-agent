# 不确定性讲解中的具体回看问题（2026-09-26）

当前默认Narration在没有可验证替代方案时只提示“需要先核实当时的可用信息和行动条件”。这保持了判断边界，但不告诉玩家具体查什么。Snapshot已有补枪窗口、目标等待、道具用途、可达替代位置等未确认条件；本轮将其用于基础三段讲解的独立问句投影。

| Before | After | Why |
|---|---|---|
| 只有笼统的不可判断/不可建议提示 | 原文保持，追加“回看时先核实 · 这些是待确认的问题” | 给出可执行的复盘下一步 |
| 内部条件无法直接读懂 | 最多三个静态中文问题，如队友能否看到同次交火并及时跟上 | 不回显内部字段/原始reason |
| 道具不存在时泛化要求核实 | 已确认空库存不问手里有什么；仅OBSERVABLE库存确认闪光才问其用途 | 不诱导不存在的方案 |

沿已应用emil/apple样式规则，当前处理区增加普通列表、rem间距与字体，无新动画/透明层/交互状态。

## 验收

5新增测试从真实Adapter生成的合成不确定cue出发，经CoachingPackage/OutcomePackage/Narration/三段投影：具体问题可见，原Narration建议文字和引用验证不变，cue.advice仍空且hasEvaluableDecision=false。JSON重载投影一致。

边界覆盖：非INSUFFICIENT或已可判断不展示；不同decisionTick、缺Snapshot、未来采样不展示；只识别UNVERIFIABLE静态条件，已确认/不可行或矛盾条件不当未知；OUTCOME和原始reason/未知字段不输出；已知空道具不生成闪光问题，已确认本人OBSERVABLE闪光才生成用途问题。

相关测试分两批运行，共81项不同测试通过（63项首批含4新项；第二批22项含新增闪光用例与17项既有展示测试，扣除4项重复）。TypeScript与production Web build通过，最后只补测试没有再改产品代码。root完成集中复查，无子任务、后台进程、模型/网络、用户Demo或数据库操作。

## 限制

只改善基础三段讲解（含跳过反思后的fallback卡）的回看方向，不提高判决置信度、不自动补证据、不把玩家回忆升级为Demo事实。问题不进入Narration/Advice/Memory或主题统计；不修改存档，不重跑Jev。自适应诊断卡已有自己的hinge/transferRule，本轮不覆写它。

验证为真实模块/合成数据，不是完整Host/浏览器视觉或真实Demo教学质量评价；原A5保持独立。下一项先检查自适应UNKNOWN诊断的具体缺条件说明与本轮问题是否一致，避免一条路径具体而另一条只给笼统拒判；若已有充分说明则不制造重复UI。
